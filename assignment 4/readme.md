# Assignment 4 — Sequence alignment

Python files for the coding questions of Practical 4, named by question number.

| File | Question |
|---|---|
| `q1.py` | Dot plot of the human and chicken haemoglobin beta chain, and the segments identical in both |
| `q2.py` | Score of the alignment AATCTATA / AAG--ATA with affine gap penalties |
| `q4.py` | Global alignment of ACAGTCGAACG and ACCGTCCG by Needleman-Wunsch |
| `q6.py` | Local alignment of ACGTATCGCGTATA and GATGCGTATCG by Smith-Waterman |

`Q3_Q5_manual_tables.xlsx` holds the two hand-worked questions: the column-by-column
check of the Q2 score, and the Needleman-Wunsch table rebuilt from the recurrence.

q1.py needs matplotlib; the rest use the standard library only.
